# 📌 Product Rollout Roadmap (8 Weeks)

This roadmap outlines the 8-week rollout plan for the Finance Tracker app, focused on driving Product-Led Growth (PLG) through a strong free tier, clear premium value, and optimized upgrade pathways.

## 🚀 Rollout Timeline

### Weeks 1–2

- [ ] Build premium scaffolding (subscription flow, paywall logic)
- [ ] Integrate analytics (PostHog/Amplitude)
- [ ] Finalize free tier experience (50 txns, 3 budgets, insights)

### Weeks 3–4

- [ ] Release first premium bundle: Unlimited + Bank Sync + Export
- [ ] Launch soft paywall for free users
- [ ] Introduce contextual upsell triggers

### Weeks 5–6

- [ ] Add Receipt OCR (basic version)
- [ ] Enable Family/SME sharing (2–3 seats)
- [ ] Refine onboarding and free-to-premium flow

### Weeks 7–8

- [ ] Optimize upgrade nudges with A/B testing (50 vs. 100 txns)
- [ ] Test paywall messages for higher conversions
- [ ] Launch light marketing push (referrals, social)

## 📦 Feature Rollout by Phase

### Free Tier (MVP)

- [ ] Anonymous flow + Hive local storage
- [ ] Auto-categorization (10 txns)
- [ ] Spending insights (graphs, top categories)
- [ ] Mini weekly report
- [ ] Soft paywall (50 txns, 3 budgets)

### Premium (Phase 1)

- [ ] Unlimited transactions & budgets
- [ ] Bank sync (Mono API)
- [ ] Export reports (PDF/Excel)
- [ ] Receipt OCR (basic)
- [ ] Family/Team sharing (2–3 seats)

### Future (Phase 2+)

- [ ] AI anomaly detection
- [ ] Advanced dashboards
- [ ] Enterprise integrations
